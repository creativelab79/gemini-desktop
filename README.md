Gemini Desktop is a lightweight Electron-based application designed for smooth performance and automatic updates.  
This project is actively maintained and distributed via GitHub Releases.

---

## ✨ Features
- Automatic updates — no manual downloads needed  
- Fast startup and stable performance  
- Clean project structure for easier maintenance  
- Electron-based cross-platform desktop app  

---

## 🚀 Installation
1. Download the latest installer from the [Releases](../../releases) page.  
2. Run `Gemini Desktop Setup <version>.exe`.  
3. The app will auto-update when new versions are published.
