## ✨ Overview
Gemini Desktop is a lightweight Electron-based application designed for smooth performance and seamless automatic updates.  
This project is actively maintained and distributed via GitHub Releases.

---

## 🚀 Features
- Cross‑platform support (Windows, macOS, Linux)  
- Automatic updates with zero manual effort  
- Lightweight footprint for fast startup  
- Simple installer for easy distribution  

---

## 📦 Installation
1. Go to the [Releases](https://github.com/creativelab79/gemini-desktop/releases) page.  
2. Download the latest installer for your operating system.  
3. Run the installer and follow the setup instructions.  
4. Launch Gemini Desktop from your applications menu.
